# 02. ข้อกำหนดความต้องการและ User Stories (Requirements & User Stories)

เอกสารนี้รวบรวม User Stories ที่ผ่านการปรับปรุงขอบเขต (Rescoped) ให้กระชับ ชัดเจน และทำได้จริงภายใน 17 วัน โดยแบ่งตามผู้รับผิดชอบ 6 คน

รายการที่เพิ่มเพื่อปิดช่องว่างเรื่องการดูประวัติ วงจร session และข้อมูลที่จำเป็นต่อการรักษา/จ่ายยา ยังเป็นรายละเอียดรอทีมยืนยันตาม D01, D02, D09 และ D11 ในเอกสาร 09–10 ไม่ถือว่าได้รับการตรวจรับแล้วเพียงเพราะเพิ่มไว้ในเอกสารนี้

---

## 1. ฟีเจอร์จัดการผู้ใช้และยืนยันตัวตน (รับผิดชอบโดย: ฟีม)
* **ผู้ป่วย (Patient):**
  * ในฐานะ *ผู้ป่วย*, ฉันต้องการ **ลงทะเบียนและล็อกอินด้วย Email และ Password** เพื่อเข้าใช้งานระบบคลินิกอย่างปลอดภัย
  * ในฐานะ *ผู้ป่วย*, ฉันต้องการ **รีเซ็ตรหัสผ่านผ่าน Email** กรณีลืมรหัสผ่าน โดยระบบจะส่งลิงก์ตั้งรหัสใหม่ไปยัง Email ที่ลงทะเบียนไว้
  * ในฐานะ *ผู้ป่วย*, ฉันต้องการ **ดูและแก้ไขข้อมูลส่วนตัว** (เบอร์โทร, ที่อยู่, ประวัติแพ้ยา/อาหาร, โรคประจำตัว) เพื่อให้แพทย์มีข้อมูลล่าสุดในการรักษา
* **เจ้าหน้าที่ / แพทย์ / เภสัชกร (Staff / Doctor / Pharmacist):**
  * ในฐานะ *ผู้ใช้งานภายในคลินิก*, ฉันต้องการ **ล็อกอินเข้าสู่ระบบด้วย Email และ Password** เพื่อเข้าถึงแดชบอร์ดการทำงานตามสิทธิ์
  * ในฐานะ *ผู้ใช้งานที่เข้าสู่ระบบ*, ฉันต้องการ **ออกจากระบบได้ และถูกขอให้เข้าสู่ระบบใหม่เมื่อ Session หมดอายุหรือใช้ไม่ได้** เพื่อไม่ให้บุคคลถัดไปเข้าถึงข้อมูลผ่าน Session เดิม
  * ในฐานะ *เจ้าหน้าที่*, ฉันต้องการ **ค้นหาข้อมูลผู้ป่วยด้วย รหัสนักศึกษา หรือ เบอร์โทรศัพท์** เพื่อตรวจสอบข้อมูลก่อนเข้ารับบริการ
* **ผู้ดูแลระบบ (Admin):**
  * ในฐานะ *ผู้ดูแลระบบ*, ฉันต้องการ **สร้าง แก้ไข และกำหนดสิทธิ์ (Roles: patient, staff, doctor, pharmacist, admin)** ให้กับผู้ใช้งานในระบบ

## 2. ฟีเจอร์ระบบจัดการแผนกและตารางเวลาแพทย์ (รับผิดชอบโดย: ช้อป)
* **เจ้าหน้าที่ (Staff):**
  * ในฐานะ *เจ้าหน้าที่*, ฉันต้องการ **เพิ่ม แก้ไข และลบข้อมูล "แผนกการรักษา"** เพื่อจัดหมวดหมู่บริการของคลินิก
  * ในฐานะ *เจ้าหน้าที่*, ฉันต้องการ **เพิ่ม แก้ไข และลบข้อมูล "แพทย์"** (พร้อมระบุแผนกที่สังกัด) เพื่อให้ข้อมูลแพทย์เป็นปัจจุบัน
  * ในฐานะ *เจ้าหน้าที่*, ฉันต้องการ **สร้างและจัดการช่วงเวลาตรวจของแพทย์ (Appointment Slots)** โดยระบุ วันที่, เวลาเริ่มต้น-สิ้นสุด, และจำนวนคนที่รับได้สูงสุด (Max Capacity)
  * ในฐานะ *เจ้าหน้าที่*, ฉันต้องการ **ดูภาพรวมตารางเวลาของแพทย์ทุกคนในรูปแบบปฏิทิน** เพื่อบริหารจัดการคิวได้อย่างสะดวก

---

## 3. ฟีเจอร์ระบบนัดหมายและประวัติการรักษา (รับผิดชอบโดย: ปาย)
* **ผู้ป่วย (Patient):**
  * ในฐานะ *ผู้ป่วย*, ฉันต้องการ **ดูตารางเวลาว่างของแพทย์และกดจองคิวนัดหมาย** ผ่านระบบได้ด้วยตนเอง
  * ในฐานะ *ผู้ป่วย*, ฉันต้องการ **ยกเลิกนัดหมายของตัวเองล่วงหน้า** เพื่อคืน Slot ให้ผู้ป่วยท่านอื่น
  * ในฐานะ *ผู้ป่วย*, ฉันต้องการ **ดูรายการนัดหมาย สถานะ และประวัตินัดหมายของตัวเอง** เพื่อทราบว่าคำขอได้รับการอนุมัติ ปฏิเสธ ยกเลิก หรือตรวจเสร็จแล้ว
  * ในฐานะ *ผู้ป่วย*, ฉันต้องการ **ดูผลตรวจ คำแนะนำ และรายการยาที่แพทย์บันทึกให้ตนเอง** เพื่อทบทวนข้อมูลหลังเข้ารับบริการ โดยไม่เห็นข้อมูลของผู้ป่วยรายอื่น
* **เจ้าหน้าที่ (Staff):**
  * ในฐานะ *เจ้าหน้าที่*, ฉันต้องการ **ดูรายการคิวตรวจของวันนี้และเปลี่ยนสถานะคิว** (รอตรวจ / กำลังตรวจ / ตรวจเสร็จ / ไม่มาตามนัด)
  * ในฐานะ *เจ้าหน้าที่*, ฉันต้องการ **อนุมัติ หรือ ปฏิเสธคำขอนัดหมาย** ที่ผู้ป่วยส่งเข้ามา
* **แพทย์ (Doctor):**
  * ในฐานะ *แพทย์*, ฉันต้องการ **ดูรายการคิวผู้ป่วยของตนเองในวันนี้เรียงตามลำดับเวลา**
  * ในฐานะ *แพทย์*, ฉันต้องการ **ดูข้อมูลสุขภาพที่จำเป็นของผู้ป่วยในคิวของตน** เช่น ประวัติแพ้ยาและโรคประจำตัว เพื่อประกอบการตรวจและสั่งยาอย่างเหมาะสม
  * ในฐานะ *แพทย์*, ฉันต้องการ **บันทึกผลการตรวจวินิจฉัย (Diagnosis), คำแนะนำการรักษา, และระบุรายการยาที่สั่งจ่าย (Prescription)** บันทึกลงในระบบ

---

## 4. ฟีเจอร์จัดการคลังยาและประวัติเวชภัณฑ์ (รับผิดชอบโดย: กัญจน์)
* **เภสัชกร (Pharmacist):**
  * ในฐานะ *เภสัชกร*, ฉันต้องการ **เพิ่ม แก้ไข และระงับการใช้งานข้อมูลยาในคลัง** (ชื่อยา, หมวดหมู่, ประเภทยา, จำนวนคงเหลือ, วันหมดอายุ)
  * ในฐานะ *เภสัชกร*, ฉันต้องการ **ดูรายการยาที่แพทย์สั่งจ่ายให้แก่ผู้ป่วยแต่ละราย**
  * ในฐานะ *เภสัชกร*, ฉันต้องการ **ดูข้อมูลผู้ป่วยที่จำเป็นต่อการตรวจทานการจ่ายยา** เช่น ชื่อผู้ป่วยและประวัติแพ้ยาที่เกี่ยวข้อง โดยไม่เห็นข้อมูลสุขภาพเกินหน้าที่
  * ในฐานะ *เภสัชกร*, ฉันต้องการ **กดยืนยันการจ่ายยาและตัดสต๊อกยาออกจากระบบ** หลังจากจัดยาเสร็จเรียบร้อย
  * ในฐานะ *เภสัชกร*, ฉันต้องการ **ดูประวัติการจัดการคลังยาย้อนหลัง (Inventory Logs)** ที่แสดงประวัติการนำเข้ายา, การจ่ายยา, หรือการปรับปรุงยอด
* **แพทย์และเจ้าหน้าที่ (Doctor/Staff):**
  * ในฐานะ *แพทย์*, ฉันต้องการ **ดูรายการยาและจำนวนสต๊อกที่พร้อมใช้งาน** เพื่อสั่งจ่ายยาได้ถูกต้องตามยาที่มีอยู่จริง

---

## 5. ฟีเจอร์ระบบแจ้งเตือนการกินยาส่วนบุคคล (รับผิดชอบโดย: กลอง)
* **ผู้ป่วย (Patient):**
  * ในฐานะ *ผู้ป่วย*, ฉันต้องการ **สร้างและแก้ไขรายการตั้งเวลาเตือนกินยา** (เลือกตัวยา, วันที่เริ่มต้น-สิ้นสุด, และเวลาเตือนในแต่ละวัน)
  * ในฐานะ *ผู้ป่วย*, ฉันต้องการ **บันทึกสถานะการกินยาในแต่ละมื้อ (กินแล้ว / ยังไม่กิน)** และดูประวัติการกินยาย้อนหลัง
  * ในฐานะ *ผู้ป่วย*, ฉันต้องการ **ปิดหรือลบรายการเตือน** เมื่อกินยาครบตามกำหนดแล้ว
* **ระบบอัตโนมัติ (System / Cron Job):**
  * ในฐานะ *ระบบ*, ฉันต้องการ **ตรวจสอบรอบเวลา สร้าง In-app Notification และส่ง Email แจ้งเตือนการกินยา** ให้ผู้ป่วยโดยอัตโนมัติตามช่วงเวลาที่ตั้งไว้

---

## 6. ฟีเจอร์ศูนย์แจ้งเตือนและแดชบอร์ด (รับผิดชอบโดย: เฮิร์บ)
* **ผู้ป่วย (Patient):**
  * ในฐานะ *ผู้ป่วย*, ฉันต้องการ **ดูกล่องแจ้งเตือนภายในเว็บ (In-app Notifications)** ที่รวมการแจ้งเตือนสถานะคิวนัดหมายและการเตือนกินยา
  * ในฐานะ *ผู้ป่วย*, ฉันต้องการ **กดทำเครื่องหมายว่า "อ่านแล้ว" หรือลบข้อความแจ้งเตือน**
* **เจ้าหน้าที่และแพทย์ (Staff / Doctor):**
  * ในฐานะ *เจ้าหน้าที่*, ฉันต้องการ **สร้างข้อความประกาศแจ้งเตือน (Broadcast)** ไปยังกลุ่มผู้ใช้งานเป้าหมายในระบบ
  * ในฐานะ *เจ้าหน้าที่*, ฉันต้องการ **ดูแดชบอร์ดสรุปสถิติภาพรวม** (เช่น จำนวนนัดหมายวันนี้, สถิติผู้ป่วยแต่ละแผนก, สถานะยาใกล้หมดสต๊อก)
  * ในฐานะ *แพทย์*, ฉันต้องการ **ดูแดชบอร์ดสรุปจำนวนคนไข้ที่ตรวจแล้วและคิวที่เหลือของตนเองในวันนี้**
