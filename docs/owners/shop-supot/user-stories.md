# User Stories — Scheduling ของสุพจน์

เรียบเรียง 24 กันยายน 2569 จาก behavior ใน code path ปัจจุบัน · เจ้าของ: ช้อป (สุพจน์) · คู่ตรวจ: ปาย

เอกสารนี้บันทึกความสามารถของโมดูลแผนก แพทย์ บริการ วันลา ตาราง และ slot ตาม route, UI, domain rule และ repository ใน code ข้อกำหนดและคำตัดสินทีมอ้างอิงจาก [08](../../08_system_rules_and_acceptance.md), [09](../../09_implementation_plan.md), [10](../../10_team_decisions.md) และ [11](../../11_functional_requirements.md)

## ผู้ป่วย (`patient`)

**US-SUP-01 — ดูตารางและเลือก slot**

ในฐานะผู้ป่วย ฉันต้องการดูและกรองตารางตามวันที่ แพทย์ และบริการ เพื่อหารอบตรวจที่เปิดรับและเลือก slot ว่างไปยังหน้าจองนัด

- ตารางแสดงสถานะ `available`, `full` หรือ `closed`
- เลือกได้เฉพาะ slot ที่ `available`; ระบบส่ง `slotId` ไป `/appointments`
- หน้า `/schedules` อ่านข้อมูลผ่าน API

## แพทย์ (`medical`)

**US-SUP-02 — ดูตารางของตนและตารางแพทย์อื่น**

ในฐานะแพทย์ ฉันต้องการเปิดตารางของตนเป็นค่าเริ่มต้นและดูตารางแพทย์คนอื่นแบบอ่านอย่างเดียว เพื่อประสานงานการออกตรวจ

**US-SUP-03 — เพิ่มบริการและจัดการ slot ของตน**

ในฐานะแพทย์ ฉันต้องการเพิ่มบริการจากหน้าตารางตรวจ และสร้าง แก้ เปิด หรือปิด slot ของตน เพื่อกำหนดรอบตรวจที่ผู้ป่วยเลือกได้ Service API อนุญาต `medical` และ `staff_admin`; slot ของแพทย์คนอื่นแก้ไม่ได้

**US-SUP-04 — จัดการวันลาของตน**

ในฐานะแพทย์ ฉันต้องการบันทึก แก้ หรือยกเลิกวันลาจากปฏิทิน พร้อมเห็นจำนวน slot เดิมที่ได้รับผล เพื่อประสานงานต่อได้

## เจ้าหน้าที่/แอดมิน (`staff_admin`)

**US-SUP-05 — ดูแลแผนกและข้อมูลแพทย์**

ในฐานะเจ้าหน้าที่ ฉันต้องการเพิ่ม แก้ และเปลี่ยนสถานะแผนกหรือข้อมูลแพทย์ เพื่อให้ข้อมูลการจัดกลุ่มความเชี่ยวชาญและบัญชีผู้ให้บริการเป็นปัจจุบัน

**US-SUP-06 — ดูแล catalog บริการ ตาราง และวันลาทั้งคลินิก**

ในฐานะเจ้าหน้าที่ ฉันต้องการเพิ่ม แก้ไข และเปิด/ปิดบริการจากหน้า `/departments` พร้อมสร้างหรือปรับ slot ของแพทย์ทุกคนและจัดการวันลา เพื่อบริหารรอบตรวจของคลินิก

- ค้นหาบริการด้วยรหัส ชื่อ หรือคำอธิบาย และเลือกแสดงบริการที่ปิดใช้งานได้
- เพิ่มหรือแก้รหัส ชื่อ และคำอธิบาย โดยการแก้ไขคง service ID เดิม

**US-SUP-07 — สร้างหลาย slot ตามคำสั่ง**

ในฐานะแพทย์ (`medical`) หรือเจ้าหน้าที่/แอดมิน (`staff_admin`) ฉันต้องการเลือกหลายวันและ time block แล้วดู preview ก่อนยืนยัน เพื่อสร้างชุด slot ที่ไม่ชนวันลาและรอบเดิม

## กติกาที่พบใน code

- สร้าง slot ได้วันจันทร์ถึงศุกร์ เวลา 08:30–16:30 น. เว้น 12:00–13:00 น.; ห้ามสร้างย้อนหลังหรือเวลาทับ slot เดิม
- ความจุต้องเป็นจำนวนบวกและไม่น้อยกว่าจำนวนจอง; ลบรอบที่มีผู้จองแล้วไม่ได้
- แพทย์จัดการ slot/วันลาของตน; `staff_admin` จัดการได้ทุกแพทย์
- รอบที่เริ่มแล้วแก้ไม่ได้; รอบที่ปิดด้วยมือและยังไม่เริ่มแก้รายละเอียดได้โดยคงสถานะปิด
- วันลาต้องไม่อยู่ในอดีต มีช่วงวันที่ถูกต้อง และไม่ซ้ำของแพทย์คนเดียวกัน; ระบบแสดงจำนวน slot ที่ได้รับผล
- บันทึก/ยกเลิกวันลาไม่เปลี่ยน slot หรือนัดเดิมอัตโนมัติ
- สร้างหลาย slot ได้เมื่อผู้ใช้สั่ง ระบบ preview ก่อนบันทึกและข้ามวันที่ลา/ช่วงที่ชนกัน

## ขอบเขตการสร้างรอบ

ไม่ใช้ weekly schedule, recurring schedule, template หรือการสร้างอัตโนมัติ; การสร้างหลาย slot ทำผ่านปุ่มสร้างแบบ Manual พร้อม preview และการยืนยันเอง ตามข้อสรุป D25
